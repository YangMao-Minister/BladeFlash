# BladeFlash - 世界空间拖尾
## 简介
基于世界空间重建和后处理模拟光栅化的世界空间拖尾。

![效果](images/0.png)

## 使用
### 纹理
![纹理布局](images/texture_layout.png)
如图所示，四个角用(11,45,14)标记；(0,1)用r,g通道编码纹理尺寸；(i+1,0)用r,g通道编码第i个拖尾顶点的uv，b通道编码第i个拖尾顶点的特效类型。
